# Agent Hub · 快速开始

#agent-hub #cli

## 环境要求

- Node.js **18+**
- macOS / Linux（Windows 为 MVP 子集）

## 安装 CLI（开发态）

```bash
git clone https://github.com/liusheldon238/agent-hub.git
cd agent-hub
npm install
npm run build --workspace=@agent-hub/cli
# 全局链接（可选）
npm link --workspace=@agent-hub/cli
```

## 三条主线命令

```bash
agent-hub list                    # 我装了什么？
agent-hub run <id>                # 在正确环境下启动
agent-hub uninstall <id> --dry-run  # 会删什么？先预览
agent-hub uninstall <id> --yes    # 确认后卸载（会先打快照）
```

## 纳管已有安装

```bash
agent-hub adopt openclaw    # 或 hermes：探测 PATH 后写入 Run Context
agent-hub inspect openclaw  # 查看足迹与配置
agent-hub disown openclaw --yes   # 仅取消纳管，不删二进制
```

## 数据目录

默认：`~/.agent-hub/`（Windows：`%USERPROFILE%\.agent-hub\`）

详见 [[agent-hub/数据与存储]]。
