# Agent Hub · 快速开始

#agent-hub #cli

目标：在**已配好的完整运行环境**里启动 Agent，而不是只确认「装没装上」。

环境 = 运行时 + Secret/env + workspace + Skill/MCP + 启动命令。详见 [[agent-hub/产品定位]]。

## 环境要求

- Node.js **18+**（开发 agent-hub 本身）
- macOS / Linux（运行 Agent 环境；Windows MVP 子集）

## 最常用：直接开工

```bash
agent-hub list                 # 看有哪些 Agent、环境是否纳管
agent-hub run <id>             # 自动切运行时、注入 env、挂 skill，再启动 Agent
agent-hub run <id> --shell     # 进入已配好的 subshell（不直接起 Agent 进程）
agent-hub config <id> --check  # 校验：运行时、secret、skill 是否就绪
```

## 图形化启动器（Mac）

1. 安装 [[agent-hub/发布与版本]] 中的 dmg
2. 打开 **agent-hub** 桌面应用 → 门户选 Agent → 启动或编辑 Run Context

适合不想记命令、需要 YAML 校验与卸载向导的场景。

## 纳管已有安装（可选）

若 Agent 是手动/curl 装的，先纳入管理再享受完整环境：

```bash
agent-hub adopt openclaw    # 或 hermes
agent-hub inspect openclaw
agent-hub run openclaw
```

## 生命周期（低频）

```bash
agent-hub uninstall <id> --dry-run
agent-hub uninstall <id> --yes
```

## 数据目录

`~/.agent-hub/agents/<id>.yaml` 即该 Agent 的**运行环境清单**。详见 [[agent-hub/数据与存储]]。

## 开发 agent-hub 本身

```bash
git clone https://github.com/liusheldon238/agent-hub.git
cd agent-hub && npm install && npm run build
npm run cli -- run <id>    # 或 npm run mac:dev 开桌面
```

见 [[agent-hub/开发指南]]。
