# Agent Hub · 快速开始

#agent-hub #cli

> **注意**：0.0.1 **不能**从「零环境」一键扫装跑。见 [[agent-hub/实现现状]]。

## 今天能走通的路径

### 1. 自行安装 Agent（工具外）

用官方方式安装，例如 `npm i -g openclaw` 或 curl 脚本。

### 2. 纳管（仅 openclaw / hermes）

```bash
agent-hub adopt openclaw
agent-hub inspect openclaw
```

### 3. 补全运行环境（必做，多为手写）

编辑 `~/.agent-hub/agents/openclaw.yaml`：runtime、env（Secret）、workspace、skills 等。

```bash
agent-hub config openclaw --check   # 校验能否启动
agent-hub run openclaw              # 在配好的环境下启动
```

### 4. 可选：工具内安装（窄）

```bash
agent-hub install openclaw --dry-run
agent-hub install openclaw --yes
```

仅 npm 全局装二进制，**不会**自动配齐 Secret/skill/workspace。

### 5. Mac 桌面

- 可：看门户、改 YAML、卸载向导  
- 不可：环境扫描、安装向导、直接替代 `run` 的完整引导  

## `scan` 能做什么、不能做什么

```bash
agent-hub scan
```

- **能**：Node/npm/磁盘/网络等体检 + openclaw/hermes 是否在 PATH  
- **不能**：列出机器上所有 Agent、检查 Run Context 是否完整、桌面展示  

## 开发 agent-hub

```bash
git clone https://github.com/liusheldon238/agent-hub.git
cd agent-hub && npm install && npm run build
npm run cli -- list
npm run mac:dev
```
