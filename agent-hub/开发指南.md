# Agent Hub · 开发指南

#agent-hub #dev

## 仓库克隆

```bash
git clone https://github.com/liusheldon238/agent-hub.git
cd agent-hub
npm install
```

## 常用脚本

```bash
npm run typecheck          # 各 workspace 类型检查
npm test                   # 测试（cli 约 170+ 用例）
npm run build              # cli + desktop bundle
npm run cli -- --help      # 构建并运行 CLI
```

### 仅 CLI

```bash
npm run build --workspace=@agent-hub/cli
```

### Mac 桌面

```bash
npm run mac:dev      # electron-vite 开发
npm run mac:build    # 编译 main / preload / renderer
npm run mac:dist     # 未签名 dmg → apps/desktop/release/
```

## 核心模块（packages/cli）

| 路径 | 职责 |
|------|------|
| `src/runtime/run-context.ts` | Run Context 读写与校验 |
| `src/inventory/` | list / inspect / 强弱信号 |
| `src/cleanup/` | uninstall 计划、快照、引用计数 |
| `src/launcher/` | 运行时策略、secret |
| `src/adapters/` | 内置 TS + 声明式 yaml |
| `src/render/` | human 输出（list / run 等） |
| `src/core.ts` | 供 Electron 主进程 import |

桌面 IPC 契约：`apps/desktop/src/shared/ipc-contract.ts`。
