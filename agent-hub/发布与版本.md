## GitHub Release

推送 **annotated tag** `v0.0.1`（及后续 `v*`）触发 CI：

```bash
git push origin main
git push origin v0.0.1
```

Workflow：`.github/workflows/release.yml` — macOS 构建 arm64 + x64 dmg。

下载：[Releases](https://github.com/liusheldon238/agent-hub/releases)
