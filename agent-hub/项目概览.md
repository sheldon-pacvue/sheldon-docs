# Agent Hub · 项目概览

#agent-hub

> **可开箱即用的 Agent 运行环境 + 方便选用与切换的人机交互启动器。**
>
> 安装与卸载是生命周期支撑；产品重心是：**一键进入已配好的完整工作环境**。

完整定位说明见 [[agent-hub/产品定位]]。

## 产品要交付什么

1. **完整运行环境**：运行时版本、Secret/env、workspace、Skill/MCP 挂载、启动入口——由 **Run Context** 统一描述，`run` 前自动就绪。
2. **人机交互启动器**：
   - **CLI / TUI**：`list` → `run`，适合日常与脚本；
   - **Mac 桌面门户**：图形选 Agent、YAML 编辑与校验、卸载向导。
3. **生命周期管理**（支撑）：盘点「装了什么」、安全卸载、纳管已有安装——不让环境债拖垮「能跑」。

## 解决的三个核心问题

| 问题 | 手段 |
|------|------|
| 换 Agent 要重配运行时、Key、目录、Skill | Run Context + `run` / 桌面门户 |
| 不知道机器上有哪些 Agent、环境是否完整 | `list` / `inspect` / `scan` |
| 想卸又怕误删共享依赖 | `uninstall --dry-run` + 快照 |
