# Agent Hub · 项目概览

#agent-hub

> **AI Agent 工具的目录 + 清理器 + 启动门户**——一处看到全部、一键切换启动、一次干净卸载。

## 解决的三个问题

1. **看得见**：散落各处的 agent 工具（npm / curl / brew / 手动安装）统一列出
2. **卸得干净**：引用计数 + diff 预览 + 快照，敢按卸载键
3. **切得无缝**：各 agent 使用各自的 Node/Python、API key、workspace、skill，互不打扰

适用平台：macOS / Linux（完整）；Windows（MVP 子集）。
