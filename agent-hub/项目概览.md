# Agent Hub · 项目概览

#agent-hub

> **目标**：可开箱即用的 Agent 运行环境 + 人机交互启动器。  
> **0.0.1 现实**：启动器**尚未**完成基本的环境扫描与安装闭环 → [[agent-hub/实现现状]]。

## 产品要交付什么（目标）

1. **完整运行环境**：运行时、Secret、workspace、Skill/MCP、入口——`run` 前自动就绪。
2. **人机交互启动器**：CLI/TUI 与桌面，支持扫描、安装引导、一键启动。
3. **生命周期**：盘点与安全卸载。

## 0.0.1 实际交付了什么

| 模块 | 状态 | 说明 |
|------|------|------|
| Run Context + `run` | ⚠️ 部分 | 已配 YAML 时可切运行时并启动 |
| Inventory `list` / `inspect` | ⚠️ 部分 | 纳管列表 + 窄弱信号（openclaw/hermes + 声明式 detect） |
| `scan` | ⚠️ 偏题 | 安装前体检，**不是**环境盘点 |
| `install` | ⚠️ 极窄 | 仅 openclaw / hermes；**不**写全量环境 |
| 桌面门户 | ⚠️ 部分 | 瓦片、YAML、卸载；**无**扫描/安装 |
| `uninstall` | ✅ | dry-run、快照、npm-global |

**今天能用的路径**：手动装 Agent → `adopt`（openclaw/hermes）→ 手写 YAML → `config --check` → `run`。见 [[agent-hub/快速开始]]。
