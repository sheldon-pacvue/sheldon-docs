# Agent Hub · 数据与存储

#agent-hub

## 目录布局

```
~/.agent-hub/
├── agents/              每个 agent 一份 Run Context（*.yaml）
├── adapters/
│   ├── builtin/         随版本发布
│   └── user/            用户/团队自定义（同 id 覆盖内置声明式）
├── inventory.json       足迹索引
├── snapshots/<runId>/   uninstall --yes 前快照
├── logs/<runId>.jsonl   结构化运行日志
├── state.json           全局状态、启动统计
└── secrets/             仅存引用，不存明文（0700）
```

## Run Context 职责划分

| 字段块 | Inventory | Cleanup | Launcher |
|--------|-----------|---------|----------|
| `source` / `footprint` | ✓ | ✓ | |
| `uninstall` | | ✓ | |
| `runtime` / `env` / `workspace` / `skills` / `mcp` / `entry` | | | ✓ |

示例 schema 见 [[agent-hub/设计/产品设计 v2]] §5。

## inventory.json

- `status`：`managed` | `detected` | `orphan`
- 含 `runCount`、`lastRunAt`、`footprintSize` 等

## 快照（uninstall --yes）

`snapshots/<runId>/` 含：

- `manifest.json`
- `uninstall-plan.json`
- `inventory.before.json`
- `run-context.before.yaml`

## 与其他工具的关系

agent-hub **只编排**，不替代：

- 运行时 → mise / nvm / fnm / pyenv / volta
- 卸载 → npm / pipx / brew 等原生命令
- Secret → Keychain / 1Password CLI 等
- Skill / MCP → 软链到 agent 期望路径
