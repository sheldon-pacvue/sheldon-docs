# Agent Hub · 命令参考

#agent-hub #cli

> 能力是否「够用」见 [[agent-hub/实现现状]]。下表为命令是否存在，非产品闭环是否完成。

> ✅ 命令存在 · ⚠️ 能力有限 · 🚧 规划中

## 主线

| 命令 | 状态 | 说明 |
|------|------|------|
| `agent-hub list` | ✅ | managed / detected / orphan；`--write-index` 刷新 inventory |
| `agent-hub run <id>` | ✅ | 运行时切换、secret、SIGINT 转发、`--dry-run` |
| `agent-hub uninstall <id>` | ✅ | `--dry-run` 计划 + shell rc 预览；`--yes` 前写快照 |

## 目录与状态

| 命令 | 状态 | 说明 |
|------|------|------|
| `inspect <id>` | ✅ | Run Context + 盘点状态 |
| `adopt <id>` | ✅ | 仅 `openclaw` \| `hermes` |
| `disown <id>` | ✅ | 删纳管 yaml，不卸二进制；需 `--yes` |
| `scan` | ⚠️ | 安装前体检（Node/网络/openclaw·hermes detect），**非**整机 Agent 环境扫描 |
| `doctor [--collect]` | ✅ | 诊断 + 可选诊断包 |

## 启动器

| 命令 | 状态 | 说明 |
|------|------|------|
| `run <id> --shell` | ✅ | 配好 env + runtime 的 subshell |
| `config <id>` | ✅ | `$EDITOR` 打开 Run Context yaml |
| `config <id> --check` | ✅ | schema / runtime / secret / skill 校验 |

## 安装（辅助）

| 命令 | 状态 | 说明 |
|------|------|------|
| `install <agent>` | ⚠️ | 仅 `openclaw` \| `hermes` \| `all`；npm 全局安装，不自动写全量 Run Context |
| `install … --dry-run` | ⚠️ | 输出 `INSTALL_PLAN` |

## Adapter

| 命令 | 状态 | 说明 |
|------|------|------|
| `adapter list` | ✅ | 已加载 adapter |
| `adapter validate <file>` | ✅ | 校验 yaml schema |
| `adapter info <id>` | ✅ | 来源与 detect 信息 |
| `adapter add <url>` | 🚧 | MVP：手动拷到 `~/.agent-hub/adapters/user/` |

## 通用契约

- `--output human|json`，json 信封 `schemaVersion: "1.0"`
- 退出码：`0` 成功 / `1` 失败 / `2` 参数 / `3` P0 阻断 / `4` 取消 / `10` 非交互缺 `--yes`
- 日志：`~/.agent-hub/logs/<runId>.jsonl`

完整设计见 [[agent-hub/设计/产品设计 v2]] §7。
