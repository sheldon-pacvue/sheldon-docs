# Agent Hub · 适配器开发

#agent-hub #adapter

## 模型

- **内置 TS adapter**：`openclaw`、`hermes`（质量高，带特殊逻辑）
- **声明式 yaml**：随包 `definitions/` 或 `~/.agent-hub/adapters/user/`

同一 `Adapter` 接口，经 Registry 加载。用户目录 **同 id 覆盖** 随包定义；`openclaw` / `hermes` 的 yaml **会被忽略**（始终走 TS）。

## 最小 yaml

```yaml
schemaVersion: "1.0"
id: my-cli
display: "My CLI"
detect:
  command: my-cli
  args: ["--version"]
  timeoutMs: 20000
```

`detect.command` 仅允许 `[a-zA-Z0-9._-]+`。

## 放置位置

| 路径 | 说明 |
|------|------|
| `packages/cli/src/adapters/definitions/*.yaml` | 随版本发布 |
| `~/.agent-hub/adapters/user/*.yaml` | 用户/团队自定义 |

## 校验

```bash
agent-hub adapter validate ~/.agent-hub/adapters/user/my-cli.yaml
agent-hub adapter list
agent-hub adapter info my-cli
```
